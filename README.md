# Proposal Website

A romantic one-page website for a love proposal.

## Run it locally

Open `index.html` in a browser.

If you want a local server:

```bash
cd C:/Users/admin/proposal-website
python -m http.server 8000
```

Then open:

http://localhost:8000

## Customize

Edit the text in `index.html` and replace `[Your Name]` with your name.
